# 手机操控实验室

独立、离线的 Android 测试软件，不需要 API Key 或特殊权限。安装 `Mobile-Control-Lab-v0.1.1.apk` 后，可手动操作，也可要求主助手打开包名 `dev.deepseek.mobile.lab`。0.1.1 将启动图标换成项目手绘矢量。

测试区域包含：文字输入和提交回显、点击次数、长按结果、密码控件、30 项竖向滚动列表、带方向和像素距离反馈的滑动面板、结果复制和重置。顶部统计实时显示已发生的操作。密码框用于验证助手的隐藏及拒绝输入行为，正常代理测试不应修改它。

示例任务：打开“手机操控实验室”，在“测试输入”填写 hello，点击“执行测试”，确认显示“结果：hello”，然后点击“点击测试”三次，长按“长按这里”，最后向上滑动列表并告诉我当前可见的编号。
